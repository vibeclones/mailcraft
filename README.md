# mailcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [MailCraft](https://github.com/MonkeySaint/mailcraft), by MonkeySaint. The newest version lives at playground.daijro.dev/mailcraft; this repo keeps older versions open-able so the timeline can be explored in a browser. This repo only mirrors upstream release zips; the code is theirs. Upstream license: MIT OR Apache-2.0.

- Latest: `/mailcraft/latest/`
- Specific version: `/mailcraft/v<version>/`
- Version list: `/mailcraft/versions.json`

Each version folder is the unmodified contents of upstream's browser build zip from the matching release. A scheduled workflow mirrors new releases.
